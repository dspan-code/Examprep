落维格 对特定长度的维度 分出不同的存本  随后单次合并为更新权重 后再拆会原有数据维度格式

并序弦 以不同特征作为基准分支 进行重复提取操作 后对特定方向进行权重放大 ,此时全局共用门控管道 或者说隐藏基长样本

———— 对连续概率以层级进行准量 其中单次的计算被称作样本 而样本与目标变化的规律做总结 能得出递归回归方位存本 此时能通过预估存本作分支对抗 外层预估提炼/深度提炼 

拆粒通路 也是我称其为进程类似体的缘故 即所有的格式本身是连续概率统计的重复描述体积 或者说分化目录组合 而其下类似独立进程的也同样是同一存本的不同处理结果 而其中对立统一的过程就是不同存本在单次反应中的不同对抗分支的总平均离散表征或者我们称之为反向传播决定方程 此时其本体反而类似 分支管道的博弈综合激活态或者说是交叉网络的特征拟合的不同维度的转换结果..一个简单的说法就是博弈
